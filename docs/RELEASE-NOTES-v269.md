# Release v2.69.0

## Bemondási fázis
- A kötelező partnerhívás külön fázisban marad, és nem számít bele a három egymást követő passzba.
- A bemondási fázist mindig a felvevő kezdi.
- A felvevő első tényleges bemondási köre szintén nem számít bele a három passz számlálásába, függetlenül attól, hogy csak Passzt mond vagy a Passz előtt egy vagy több bemondást tesz.
- A felvevő első bemondási körében továbbra is lehet több bemondást tenni, majd Passzt mondani; ezt követően a következő játékosok tiszta Passzai számlálódnak.
