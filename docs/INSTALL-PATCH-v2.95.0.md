# Installing the 2.95.0 patch

1. Back up the current project folder first.
2. Extract the patch ZIP into the project root and allow the included files to overwrite existing files.
3. Upload the changes to GitHub and wait for Render to finish the deployment.
4. Hard-refresh the page with Ctrl+F5. Verify the declaration phase with four seats and rotate the taker through all seats.
5. Check these cases: (a) partner's first declaration/8-9 tarokk makes partnership public; (b) defender must contra before declaring; (c) after B's contra, C can declare as defender; (d) if C passes and D is the hidden partner, D must recontra before declaring; (e) recontra or a second defender declaration resolves the pairs without exposing hidden roles earlier.

The patch is intended for the 2.94.0 project. It includes the new release files and version bump to 2.95.0. It has not yet been deployed to Render.
